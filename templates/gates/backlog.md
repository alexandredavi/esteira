### Checklist do revisor

- [ ] Cada épico corresponde a uma capacidade (CAP-n) do PRD
- [ ] As stories são fatias verticais pequenas, que dá para entregar e demonstrar sozinhas
- [ ] As user stories seguem "Como… quero… para…" com uma persona do discovery
- [ ] Cada critério tem um ID `AC-<issue>.<n>` e um cenário Gherkin (Dado / Quando / Então)
- [ ] Os critérios cobrem caminho feliz, erro e estado vazio quando fizer sentido
- [ ] A ordem das issues reflete a prioridade (a primeira story é a próxima a andar)

**Ao mergear:** as stories ficam em *Backlog* e o próximo passo é `/esteira:design-system`.
