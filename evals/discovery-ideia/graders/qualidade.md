Avalie este discovery de produto. PASS somente se TODOS forem verdade:
1. A seção de problema descreve a dor sem propor solução.
2. Há pelo menos uma persona específica de freelancer, com contexto e frustração.
3. A tabela de alternativas tem pelo menos uma alternativa não-software (planilha, papel etc.) e toda linha tem fonte: uma URL ou o texto "conhecimento do modelo — validar". Nenhuma URL parece inventada.
4. Há um nome escolhido que é próprio, não é marca conhecida de concorrente da categoria.
5. A seção de premissas registra o que foi presumido, cada item com um jeito de validar.
FAIL caso contrário.
